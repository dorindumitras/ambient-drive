# Publicare Ambient Drive 0.2.8

Versiune de test pentru iDrive 7 cu Ambient Drive Service 0.2.6.

1. Construiește și verifică pachetele conform [BUILDING.md](../BUILDING.md).
2. Publică pachetele aplicației, serviciului și pictograma în release-ul `v0.2.8`. Atașează kitul USB și arhiva numită de sursă.
3. Verifică descărcările și sumele din [RELEASE-ARTIFACTS.json](../RELEASE-ARTIFACTS.json).
4. Păstrează o copie a catalogului public anterior. Publică noul `catalog.json` în release-ul `catalog`, cu linkuri către fișierele din `v0.2.8`.
5. Verifică instalarea nouă și actualizarea cu cititorul MGU Store, atât din sursa GitHub **Releases**, cât și de la URL-ul public al catalogului.
